# Episodes and dependent variables

The released label is retained only as `source_wikidisputes_escalated`: evidence
of the source sampling/alignment outcome. The negative class is not resolved,
constructive, successful, or consensual.

Episode index version `source-projection-end-v1` is derived from source sampling
evidence, not a future event. Raw events before or at it remain in the SSOT and are
labeled `pre_index`/`at_index`; only post-index events can be future outcomes.
Because the literature does not establish a unique primary formal horizon, 30-,
90-, 365-day and full-follow-up views are retained and the primary choice remains
methodologically pending.

Four independent candidate definitions are emitted:

- venue-specific formal escalation (currently source-evidenced DRN; other venues
  await historical extraction);
- durable tag clearance and recurrence by versioned family/scope;
- deterministic SHA-1 identity-revert stability at 7/30/90 days;
- process-conditional closure category/time.

Each row stores applicability, observation status, value/time/horizon, censoring
reason, evidence, method/confidence and manual-validation state. Unknown or
not-observable is never false. No definition is a composite resolution score, and
none is human-validated until its review packet has actual adjudications.

The revert extractor resolves article titles to stable page IDs in API batches,
requests one pre-window baseline revision, streams metadata-only revision history
through 365 days, and detects full identity reverts from repeated SHA-1 states.
Revert tags are corroborating evidence only. Section-scoped stability remains
`not_observable`; the emitted measure is explicitly an article-level sensitivity.
